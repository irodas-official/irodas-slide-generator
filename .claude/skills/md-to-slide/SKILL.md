# マークダウンからスライド作成スキル

マークダウンファイルを読み取り、内容を分析してHTMLスライドデッキに変換する。

## ワークフロー

1. 指定されたマークダウンファイルを読む
2. 内容を分析し、以下のルールでスライド構成に変換する
3. 構成をユーザーに提示して承認を得る
4. 各スライドを生成
5. `pnpm validate` で検証

## マークダウン → スライド変換ルール

### 見出しの解釈
- `# h1` → **カバースライド**のタイトルとして使用
- `## h2` → **中扉スライド**（セクション区切り）として使用
- `### h3` → 各コンテンツスライドの**見出し**として使用

### コンテンツの解釈
- 箇条書き（`-` / `*`） → **content-text** テンプレートで箇条書きスライド
- 表（`| ... |`） → **table** テンプレートでテーブルスライド
- 数値データが並ぶ箇所 → **cards** テンプレートでKPIカード、または **chart-bar** で棒グラフ
- 強調テキストだけの短い段落 → **key-message** テンプレート
- その他のテキスト → **content-text** テンプレート

### 自動判定のヒント
- `---` や `***`（水平線）→ スライドの区切りとして解釈してもよい
- 画像リンク `![alt](path)` → スライド内に `<img>` として配置
- コードブロック → コードハイライト付きスライドとして生成

### 情報が多すぎる場合
- 1スライドに詰め込まず、適切に分割する
- 箇条書きは1スライドあたり最大5項目を目安に

## スライド生成ルール

create-slide スキルの生成ルールに従うこと（HTMLヘッダー、デザイン、viewer.html更新など）。
